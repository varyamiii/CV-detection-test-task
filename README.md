# CV-detection-test
Проект выполняет детекцию людей в видео (crowd.mp4) и сохраняет выходное видео с отрисованными bounding box'ами и уровнями уверенности.
# Кратко
- Модель детекции: Faster R-CNN (ResNet-50 + FPN) из torchvision, предобученная на COCO. Модель загружается автоматически при первом запуске (нужен Интернет для скачивания весов).
- Вход: crowd.mp4 (положите в корень проекта, рядом с main.py)
- Выход: outputs/result.mp4 (по умолчанию). Папка outputs/ создаётся автоматически при запуске, если её нет.
- Запуск по умолчанию: python main.py — все аргументы берутся из main.py (см. ниже).
- Альтернативный запуск: указывать явным образом аргументы командной строки (см. раздел Примеры запуска).

# Что делает проект

- Читает входной видеофайл.

- Для каждого кадра (или для каждого N-го кадра, если задан --skip) выполняет инференс модели Faster R-CNN и выбирает детекции класса person.

- Отрисовывает вокруг каждого обнаруженного человека прямоугольник и подпись person <confidence> (полупрозрачный фон для читаемости).

- Собирает кадры и сохраняет выходное видео в указанный файл.

- Отрисовка сделана так, чтобы не закрывать сильно исходный кадр и при этом обеспечивать читаемость метки и уровня уверенности.

# Аргументы командной строки (и значения по умолчанию)
Аргументы описаны в main.py. Запуск python main.py без аргументов использует значения по умолчанию:

- **--input**, -i — путь к входному видео

    По умолчанию: crowd.mp4

    Пример: --input crowd.mp4 или --input /path/to/video.mp4

- **--output**, -o — путь для сохранения выходного видео

    По умолчанию: outputs/result_2.mp4

    Пример: --output outputs/result.mp4

- **--device**, -d — устройство для запуска модели: 'cpu' или 'cuda'

   По умолчанию: cpu

    Пример: --device cuda (чтобы использовать GPU, если у вас установлен PyTorch с поддержкой CUDA)

- **--confidence**, -c — порог уверенности для отбора детекций (0.0 — 1.0)

    По умолчанию: 0.5

    Пример: --confidence 0.6

- **--skip** — обрабатывать каждый N-й кадр (ускорение; int)

    По умолчанию: 1 (обрабатывать все кадры)

    Пример: --skip 2 (обрабатывать каждый второй кадр)

# Примеры запуска
Запустить с параметрами по умолчанию (убедитесь, что crowd.mp4 находится в корне проекта):
```bash
python main.py
```
Явный запуск с перечислением аргументов:
```bash
python main.py --input crowd.mp4 --output outputs/result.mp4 --confidence 0.5 --device cpu --skip 1
```
Запуск с использованием GPU (если PyTorch собран с поддержкой CUDA и драйверы установлены):
```bash
python main.py --device cuda --input crowd.mp4 --output outputs/result_2.mp4 --confidence 0.6
```
